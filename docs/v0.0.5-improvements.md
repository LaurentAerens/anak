## Detailed Step Logs

### Step 1.1 & 1.2: Improving Heuristic & Reverse Futility Pruning
- **Date**: 2026-10-23
- **Files Modified**: `src/Anak.Search/Minimax/AlphaBetaEngine.cs`
- **Description**:
  - Implemented the `improving` flag in search: a position is improving if the current static evaluation is greater than the static evaluation 2 plies ago (or 4 plies ago if ply-2 was in check).
  - Conditioned Reverse Futility Pruning on `improving`: when improving, `rfpMargin` is scaled by $1.3\times$, requiring a larger margin above beta before pruning.
- **Match Results**:
  - **Opponent**: Anak v0.0.4 Baseline (1678 Elo)
  - **Match Settings**: 250 games, TC: 3s + 0.05s, 16 threads, 64 MB Hash
  - **Score**: 133.5 / 250 (98 Wins, 81 Losses, 71 Draws) &rarr; 53.40%
  - **Elo Difference**: **+23.66 &plusmn; 36.09** (LOS: 90.21%)

### Step 1.3: Improving Heuristic in Null Move Pruning (NMP)
- **Date**: 2026-10-23
- **Files Modified**: `src/Anak.Search/Minimax/AlphaBetaEngine.cs`
- **Description**: Tested increasing null move reduction $R$ ($r{+}{+}$) when `improving == true`.
- **Match Results**:
  - **Opponent**: Anak v0.0.4 Baseline
  - **Score**: 119.5 / 250 (84 Wins, 95 Losses, 71 Draws) &rarr; 47.80% (-15.3 Elo)
- **Action**: **Reverted**. NMP already dynamically scales reduction via `(eval - beta) / 200`; additional reduction caused tactical over-pruning.

### Step 1.4: Improving Heuristic in Late Move Reductions (LMR)
- **Date**: 2026-10-23
- **Files Modified**: `src/Anak.Search/Minimax/AlphaBetaEngine.cs`
- **Description**: Added an extra 1-ply reduction ($r{+}{+}$) to quiet moves when the position is not improving (`!improving`), spending less time exploring unpromising lines.
- **Match Results (Direct Head-to-Head vs Previous `main`)**:
  - **Opponent**: `Anak main` (with Step 1.1 & 1.2)
  - **Match Settings**: 250 games (125 opening pairs, color reversal), TC: 3s + 0.05s, 16 threads, 64 MB Hash, `openings.epd`
  - **Score**: **149.0 / 250** (113 Wins, 65 Losses, 72 Draws) &rarr; **59.60%**
  - **Elo Difference**: **+67.55 &plusmn; 37.42**
  - **Likelihood of Superiority (LOS)**: **99.99%**
  - **PGN Archive**: `tools/fastchess/results/anak_dev_vs_main_20261023_212401.pgn`
- **Action**: **Accepted into `main`**.
